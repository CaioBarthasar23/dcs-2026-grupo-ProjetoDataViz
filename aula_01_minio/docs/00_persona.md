# 00. Persona

> Etapa 1 do SDD. Preenchido pelo prompt 1 (Persona) e revisado pelo grupo.
> Descreva pessoas reais do problema, não o agente. Uma persona principal basta;
> acrescente secundárias só se elas tomarem decisões diferentes.

## Persona principal

| Campo | Descrição |
|---|---|
| Nome e papel | Engenheiro de dados do grupo, aluno de MBA em Engenharia de Dados. |
| Contexto | Trabalha com o grupo em um único repositório público; cada integrante desenvolve no próprio ambiente de trabalho. O projeto será usado nas Aulas 02, 03 e 04 e no projeto final. |
| Decisão que toma com o dado | Decide onde guardar o JSON bruto coletado e se o grupo pode reaproveitar a coleta de um colega nas Aulas 03 e 04 e no projeto final. |
| Dor atual | Cada integrante guarda arquivos no próprio ambiente de trabalho; quando esse ambiente é apagado, os dados coletados somem e ninguém consegue reproduzir a coleta do colega. |
| Frequência de uso | A gravação de JSON bruto será horária. A frequência com que o próprio engenheiro acessa os dados para ler ou conferir não está definida: hipótese: validação pendente. |
| O que considera sucesso | Manter os dados coletados disponíveis e reproduzíveis durante o semestre, para que o grupo possa reaproveitar a coleta de um colega nas aulas seguintes e no projeto final. |
| O que não aceita | Que os dados coletados desapareçam com o ambiente individual de quem fez a coleta ou que o grupo não consiga reproduzi-la. |
