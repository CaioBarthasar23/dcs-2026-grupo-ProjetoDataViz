# ADR-001 · HTTP publica na fila

**Status:** Proposta
**Requisitos:** RF-01, RF-02, RF-03.

## Contexto

A API recebe envelopes HTTP. O fluxo esperado valida o envelope, publica mensagem persistente na fila durável com confirmação do broker e só então responde 202. A API não grava diretamente no lake ou no ClickHouse.

## Decisão

A API publica os envelopes válidos na fila `ingestao`; o consumidor é responsável pelo processamento e pelas gravações.

## Alternativas

| Alternativa descartada | Motivo |
|---|---|
| API grava diretamente no lake e no ClickHouse | Acopla a resposta HTTP a todas as etapas e não segue RF-01. |
| API grava diretamente no ClickHouse | Ignora persistência no lake e o caminho comum do consumidor. |

## Consequências

Há confirmação de publicação antes da resposta 202 e processamento desacoplado. Prefetch, DLX e deduplicação ficam para a Aula 06.
