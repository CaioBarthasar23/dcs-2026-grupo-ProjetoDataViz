# ADR-005 · Tabela comum de três colunas com data_json JSON

**Status:** Proposta
**Requisitos:** RF-07, RF-08, RNF-03, RNF-04.

## Contexto

Os domínios compartilham ingestão e lake, mas os objetos em `data` variam. O modelo definido tem `timestamp UInt64`, `data_json JSON` e `data_tag LowCardinality(String)`.

## Decisão

Usar a tabela comum de três colunas descrita em `specs/03_modelo_de_dados.md`, mantendo o conteúdo como JSON no ClickHouse e sem colunas por domínio.

## Alternativas

| Alternativa descartada | Motivo |
|---|---|
| Uma tabela e colunas tipadas por domínio | Exige esquema específico e DDL para cada fonte, contrariando RNF-03 nesta etapa. |
| Armazenar `data_json` como String | Não atende RF-08, que exige o tipo JSON do ClickHouse. |

## Consequências

O esquema comum aceita variação de campos e permite consulta por caminhos JSON; os campos internos ainda não são validados pelo contrato desta aula. Esquemas por domínio pertencem à Aula 07.
